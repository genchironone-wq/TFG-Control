# Общий мир — обновлённый TFG Control 1.1.0

Новый матовый интерфейс с мягкими тенями и спокойными цветами. В центре — вращаемая блочная 3D-планета с деревьями и водой. На ней появляются ники игроков онлайн и маленькие аватары.

**Ники и количество — с сервера. Позиции на планете условные: это иллюстрация, а не настоящая карта или координаты игроков.**

Главный экран: запуск, сохранение, остановка; игроки, память, нагрузка и плавность. График памяти перенесён в «Показатели», подробный журнал — в «События». Подсказки и названия упрощены. Планета рисуется внутри приложения, без загрузки изображений или скинов из интернета.

## Если сервер уже установлен

1. Остановите сервер старой панелью, дождитесь сохранения мира, закройте панель.
2. Скачайте **`TFG-Control.exe`** и замените только этот файл в папке сервера.
3. Не заменяйте `world`, настройки и остальные файлы сервера.

## Для нового сервера

Скачайте **`TerraFirmaGreg-0.13.18-Control-Windows-v1.1.0.zip`**, распакуйте целиком в новую папку и запустите `TFG-Control.exe`. Внутри сервер TerraFirmaGreg 0.13.18, Forge 47.4.13 и Java 17, лимит памяти по умолчанию 8 ГБ. Соглашение Minecraft хост подтверждает сам при первом запуске.

Проверены отрисовка экранов, обработка метрик и тестовый процесс сервера: запуск, игроки, маркеры планеты, замер памяти, TPS, сохранение JVM-флагов и штатная остановка.

Настройка сети выполняется отдельно. Комплект без проверки лицензии предназначен для закрытой компании друзей. Подключение из интернета на компьютере будущего хоста не проверено.
