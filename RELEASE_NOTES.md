# TFG Control 1.0.0

Панель для TerraFirmaGreg-Modern 0.13.18, Minecraft Java 1.20.1 и Forge 47.4.13.

**Для нового хоста:** скачайте `TerraFirmaGreg-0.13.18-Control-Windows.zip`, распакуйте полностью в новую папку и откройте `TFG-Control.exe`. Java 17 уже внутри; серверу по умолчанию выделяется до 8 ГБ.

**Если готовая папка сервера уже есть:** отдельный `TFG-Control.exe` положите рядом с папками `java17`, `libraries`, `mods` и файлом `user_jvm_args.txt`.

Запуск, сохранение мира и остановка кнопками; выбор памяти и мест; игроки; график Java heap; CPU и TPS; подсказки о нагрузке; журнал и копирование сетевого адреса.

Проверены парсер метрик и управление тестовым процессом. Реальный сервер проверен до запроса соглашения Minecraft; соглашение заранее не принято.

Подключение друзей требует отдельно настроенной сети. Готовый комплект без проверки лицензии предназначен для закрытой компании; не публикуйте его игровой порт в открытый интернет.

Архив проверен по CRC; контрольная сумма SHA-256 приложена отдельно. Компоненты TerraFirmaGreg, Forge и Java принадлежат их авторам, уведомления о лицензиях сохранены.
