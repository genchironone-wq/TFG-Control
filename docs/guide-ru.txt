ОБНОВЛЕНИЕ 1.1 — ОБЩИЙ МИР
Новый матовый интерфейс и блочная 3D-планета, которую можно вращать мышью.
Маркеры показывают реальных игроков онлайн, но их позиции условные.
Это иллюстрация, не карта чанков и не настоящие координаты игроков.
На планете видно до 10 маркеров, все ники — в разделе «Игроки».
Плавность игры показывается по шкале до 20 (игровых тиков в секунду).
График памяти находится в «Показатели», журнал — в «События».

ОБНОВЛЕНИЕ УЖЕ РАБОТАЮЩЕГО СЕРВЕРА
Остановите сервер через старую панель, дождитесь сохранения и закройте её.
Замените только TFG-Control.exe. Не заменяйте папку world и свои настройки.
Полный ZIP нужен для установки нового сервера в новую папку.

TFG CONTROL — СЕРВЕР ДЛЯ ДРУЗЕЙ
Windows 10/11 x64. TerraFirmaGreg-Modern 0.13.18.
Minecraft Java 1.20.1 / Forge 47.4.13 / вложенная Java 17.

БЫСТРЫЙ ЗАПУСК ДЛЯ ХОСТА
1. Распакуйте ВЕСЬ архив в новую папку, например D:\TFG-Server.
   Не запускайте EXE из окна архива. Не кладите комплект в .minecraft.
2. Откройте TFG-Control.exe. Установка, права администратора и браузер
   для панели не нужны. Консольное окно при запуске сервера не открывается.
3. При необходимости выберите лимит ОЗУ во вкладке «Настройки»
   и нажмите «Сохранить настройки». По умолчанию — 8 ГБ, минимум 1 ГБ
   выделяется при старте. Оставьте запас для Windows и своей игры.
4. Нажмите «Запустить сервер». На первом запуске прочитайте соглашение
   Minecraft по ссылке в диалоге. Если согласны, подтвердите сами.
   Соглашение заранее не принято. Отмена не запускает сервер.
5. Дождитесь статуса «Работает». Первое включение сборки и создание мира
   могут занять несколько минут. Журнал находится во вкладке «События».
6. Запустите свою КЛИЕНТСКУЮ сборку и зайдите в Сетевую игру →
   Прямое подключение → localhost:25565.
7. Когда закончите — «Остановить». Дождитесь статуса «Остановлен».
   Мир сохраняется перед выключением. При закрытии панели она предлагает
   остановить сервер. Не выключайте ПК, пока сервер сохраняется.

ЧТО ПОКАЗЫВАЕТ ПАНЕЛЬ
Игроки: число и ники, сверка с сервером примерно каждые 16 секунд.
Память Java heap: занятая память игровых объектов; проверка jcmd каждые
16 секунд. График показывает последние 2 минуты. Память всего процесса
в ОЗУ указана отдельно и может отличаться от Java heap и её лимита.
CPU: доля всех логических процессоров, используемая сервером.
TPS: ответ команды forge tps примерно каждые 30 секунд после готовности.
Цель — 20 TPS и до 50 мс на тик. Если измерения недоступны или устарели,
панель показывает прочерк, а не придуманные значения.
Первые показатели появляются с задержкой после старта.

ПОДСКАЗКИ О НАГРУЗКЕ
Если heap заполнена минимум на 88% три замера подряд и на ПК есть запас,
панель предложит добавить 2 ГБ после остановки. Если на всём ПК осталось
меньше 2 ГБ свободной ОЗУ, она предложит освободить память.
Падение TPS при свободной heap не трактуется как нехватка ОЗУ:
возможны нагрузка механизмов, генерация мира или процессорное ограничение.
Число игроков само по себе не позволяет вычислить нужную память.
Панель не меняет лимит автоматически. Изменения действуют после перезапуска.
Кнопка «Сохранить мир» отправляет save-all flush.

ДРУЗЬЯ ИЗ ДРУГИХ ДОМОВ
Сначала соедините хоста и игроков одной ЗАКРЫТОЙ виртуальной сетью.
Во вкладке «Подключение» хост выбирает адрес нужного сетевого адаптера
и копирует его. Вставьте этот адрес в «Прямое подключение» своей игры.
Адрес друга выглядит как АДРЕС_ХОСТА:25565, а НЕ localhost.
Наличие адреса в панели не означает доступность извне: проверьте общую
сеть, брандмауэр и порт. Панель не открывает порты и не меняет сеть Windows.
Обычный VPN для выхода в интернет сам по себе не соединяет игроков.
Для встроенного голосового чата может потребоваться UDP 24454
(проверьте config/voicechat/voicechat-server.properties).

ЛИЦЕНЗИЯ И TLAUNCHER
Настроено online-mode=false и enforce-secure-profile=false.
Могут играть клиенты без проверки лицензии и лицензионные аккаунты.
Владелец ника НЕ проверяется. Используйте только закрытую сеть знакомых,
не выставляйте этот комплект в открытый интернет. У всех разные ники.
Не меняйте ник постоянно, чтобы не потерять привязку персонажа.
Никому не передавайте пароли Microsoft. Лаунчеры могут быть разными.
У каждого игрока должна стоять полная TerraFirmaGreg-Modern 0.13.18,
Minecraft Java 1.20.1 и Forge 47.4.13. Сервер не заменяет клиентскую сборку.
Если хотите только лицензионные аккаунты, после остановки измените
online-mode=true и enforce-secure-profile=true в server.properties.

МИР И ОШИБКИ
Мир находится в папке world рядом с EXE. Не удаляйте её.
Перед обновлениями делайте копию папки world при остановленном сервере.
Не запускайте одновременно панель и BAT для одной папки.
Если порт занят — остановите предыдущую копию сервера.
Если ошибка повторяется, откройте полный журнал кнопкой во вкладке
«Журнал» и пришлите logs/latest.log. Он может содержать ники и адреса.
После двух минут ожидания остановки появится кнопка принудительного
завершения. Оно может потерять несохранённые изменения — используйте
только если сервер завис и обычная остановка не помогает.
Запасной способ запуска — start_server.bat, если панель недоступна.

ПРОВЕРКИ И ОГРАНИЧЕНИЯ
217 серверных модов сверены с официальным архивом. Forge установлен.
Реальный сервер проверен до запроса EULA, без принятия соглашения.
Парсер и управление проверены отдельным тестовым процессом: запуск,
игроки, TPS, heap, штатная остановка, сохранение настроек и JVM-флагов.
Доступность из интернета и реальная нагрузка у будущего хоста не проверены.
Панель не скачивает обновления, не отправляет метрики и не работает
через веб-сервис; она читает локальный процесс и журнал сервера.
